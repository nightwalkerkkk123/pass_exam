# 0002 · 堆专题掌握 + 堆排序方向（顽固易错点）

2026-08-02 啃完整堆专题：堆是什么（完全二叉树 + 堆序性 + **非 BST**、根=最值）、数组存储与下标算式（0 起始 `left=2i+1` `right=2i+2` `parent=(i-1)/2`）、插入+上浮、取最值+下沉、heapify 建堆 **O(n)**——**均验证过关**。merge sort 的"先分到底再合上来、合的两边必须已有序"也验证过关（复杂度 `O(n log n)` 待一句补）。
