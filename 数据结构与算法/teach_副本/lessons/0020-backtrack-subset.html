回溯法图解 · 以子集问题为例

选，还是不选？—— 回溯的“撤销选择”到底在干什么

用 nums = [1, 2] 求所有子集，看懂为什么代码里必须“先选 → 递归 → 撤销”。

一、问题

给定数组 [1, 2]，返回所有子集：

[]、[1]、[2]、[1,2]

每个数有两种命运：选它 或 不选它。我们要把所有可能的组合都枚举出来。

二、决策树：每个数做一次二选一

起点
path = []
选 1不选 1
[1]
[]
选 2不选 2选 2不选 2
[1,2]
[1]
[2]
[]

每个叶子结点就是一个完整子集。回溯法就是按“深度优先”的顺序，从左到右走遍所有叶子。

三、伪代码：骨架只有三步

void backtrack(nums, depth) {
    if (depth == n) {
        把当前 path 加入答案;
        return;
    }

    // 分支 A：不选 nums[depth]
    backtrack(nums, depth + 1);

    // 分支 B：选 nums[depth]
    path[depth] = nums[depth];   // 做选择
    backtrack(nums, depth + 1);

    // 撤销选择（把刚才放的值清掉，让 path 恢复成“没选”的状态）
    path[depth] = 0;             // 或者把 path 长度减 1
}

四、一步一步走：为什么必须撤销？

第 1 步：在起点，path = []，depth = 0，准备处理 nums[0] = 1。
第 2 步（不选 1）：直接调用 backtrack(nums, 1)。
此时 path 还是空，继续处理 nums[1] = 2。
第 3 步（不选 2）：调用 backtrack(nums, 2)。
depth == n，收集 []。然后返回上一层。
第 4 步（选 2）：返回后，path 仍然是空（因为第 3 步没做选择）。
现在选 2：path[1] = 2，调用 backtrack(nums, 2)。
收集 [2]。返回。
第 5 步（撤销选 2）：path[1] = 0，path 恢复为空。
然后这一层结束，返回到 depth = 0。
第 6 步（选 1）：现在回到起点，准备走“选 1”这一支。
path[0] = 1，调用 backtrack(nums, 1)。
第 7 步（不选 2）：path = [1]，调用 backtrack(nums, 2)。
收集 [1]。返回。
第 8 步（选 2）：path = [1]，再选 2，path = [1, 2]。
收集 [1, 2]。返回。
第 9 步（撤销选 2、再撤销选 1）：path 依次恢复为 [1]、[]，全部结束。

五、如果不撤销，会发生什么？

假设我们把“撤销”删掉：

void backtrack_bad(nums, depth) {
    if (depth == n) { 收集 path; return; }

    backtrack_bad(nums, depth + 1);        // 不选

    path[depth] = nums[depth];             // 选
    backtrack_bad(nums, depth + 1);        // 递归
    // 没有撤销！！
}
bug 示例：
  1. 起点：path = []，先走“不选 1”分支。
  2. 走到“选 2”分支，path 变成 [2]，收集 [2]。返回。
  3. 现在返回起点，但该死的 path 还是 [2]！
  4. 接下来走“选 1”分支，path[0] = 1，path 变成 [1, 2]，但 2 是上一轮“不选 1”分支留下的垃圾。
  5. 最终你会收集到 [1, 2]、[] 被污染成 [2] 等错误结果。

结论：不撤销，path 就会被上一分支的状态污染，兄弟分支之间互相串味，结果全错。

六、类比：餐厅占座

想象一家餐厅有 2 张桌子，你要安排客人 1 和 2 是否入座。每张桌子同一时间只能有一位客人。
  • 你先让客人 2 坐在桌子 B 上拍照（收集答案 [2]）。
  • 拍完照，必须把客人 2 请走（撤销选择），桌子 B 才能空出来。
  • 然后你才能重新安排：客人 1 坐 A、客人 2 坐 B，拍照 [1,2]。
如果不请走客人 2，后面所有照片里都会多一个不该出现的 2。

七、全排列 vs 子集：骨架一样，只是“选择列表”不同

问题每一层的选择是什么需要 used[] 标记吗
子集第 i 个数：选 / 不选不需要
全排列第 i 个位置：从还没用过的数里挑一个需要

全排列的撤销是 used[i] = 0，子集的撤销是 path[depth] = 0（或把 path 长度减回去）。本质一样：让共享的 path 回到进入当前分支之前的状态。
