## 主题 1：HTTP/1.1 → HTTP/2 → HTTP/3 演进  ✅ 已验证（选择题 4 连对）

### ① 问题本身
- [x] HTTP/1.1 的核心痛点：队头阻塞（HOL）、连接利用率、头部冗余
- [x] keep-alive 解决了什么，又没解决什么
- [x] HTTP/2 解决了应用层 HOL，但为什么 TCP 层又冒出新的 HOL
- [x] HTTP/3 要彻底解决传输层 HOL，为什么必须换掉 TCP

### ② 解决方案
- [x] HTTP/2：二进制分帧 + 多路复用 + HPACK 头部压缩 + Server Push
- [x] HTTP/3：改用基于 UDP 的 QUIC，把"传输层 + 加密"合并到一起
- [x] QUIC 的流（stream）独立，丢一个包不再阻塞其他流

### ③ 宏观背景
- [x] 为什么演进到 HTTP/2 还不够（网页资源越来越多、移动端弱网）
- [ ] 为什么 Google/Cloudflare 力推 HTTP/3（未深挖，速记即可）

### 面试速记口诀
HTTP 每代都在治**队头阻塞**：1.1 应用层 HOL（多开连接硬扛）→ 2 多路复用治好应用层 HOL，却因共跑一条 TCP 引入 **TCP 层 HOL** → 3 换 QUIC(UDP)，流独立可靠，根治。

> ⚠️ 开放式复述未做，留到综合验证环节。

## 主题 2：HTTPS 完整握手 & TLS 1.3 精简  ✅ 已验证

### ① 问题本身
- [x] HTTP 为什么不安全（明文、可篡改、可伪装身份）
- [x] 为什么不能直接用对称加密（密钥怎么协商）
- [x] 为什么不能全程非对称加密（性能差几个数量级）

### ② 解决方案
- [x] HTTPS = HTTP + TLS 的分层关系（TLS 在传输层之上、应用层之下）
- [x] 混合加密：非对称协商出会话密钥 → 对称加密通信
- [x] 数字证书 + CA 链：解决"公钥怎么可信"（证书验身份，不是加密）
- [x] TLS 1.2 完整握手的报文序列，共 2 个 RTT
- [x] TLS 1.3 砍到 1-RTT 握手的关键：去掉 RSA 密钥交换、只保留 (EC)DHE
- [x] 0-RTT 的工作原理与重放攻击风险（PSK / Session Ticket）

### ③ 宏观背景
- [x] 握手 RTT 对移动端弱网的影响有多大（每 1 RTT 可能几百 ms）
- [x] TLS 1.3 删掉一批旧算法的本质原因：安全性与握手轮次耦合（前向安全性）

### 面试速记口诀
HTTPS = HTTP + TLS；混合加密（非对称商量密钥、对称传数据）；证书验身份；TLS1.2 = 2-RTT，TLS1.3 删 RSA 只留 (EC)DHE → 1-RTT；0-RTT 靠 PSK 但怕重放，只限幂等。

### ⚠️ 错因记录
反向提问"哪条错误"踩坑：误选了正确的描述。知识本身已掌握（懂得 0-RTT 有重放风险）。**对策：看到"不正确/错误/除外"先圈题干关键词。**

## 主题 3：TCP 四次挥手 & 为什么等 2MSL  ✅ 已验证

### ① 问题本身
- [x] 为什么断开要四次，而建立连接只要三次（全双工，每边都要单独关）
- [x] TIME_WAIT 出现在哪一边（主动关闭方），为什么需要这个状态
- [x] 如果不等 2MSL，会出现哪两类故障

### ② 解决方案
- [x] 四次挥手每一步 + 状态机：FIN_WAIT_1/2 / TIME_WAIT / CLOSE_WAIT / LAST_ACK
- [x] 2MSL 的两个作用：① 让旧报文消亡 ② 保证对方能收到最后 ACK
- [x] 为什么是 2 倍 MSL：ACK 最长存活 1 + 重发 FIN 最长 1 = 2 MSL（最坏上界）

### ③ 宏观背景
- [x] MSL vs TTL vs RTT 的区别（TTL=跳数；MSL=报文存活时间；RTT=往返时延）
- [x] TIME_WAIT 过多 vs CLOSE_WAIT 过多（CLOSE_WAIT 才是 bug 信号）
- [ ] TIME_WAIT 过多的缓解手段（SO_REUSEADDR / 调短 / 长连接，未深挖）

### 面试速记口诀
挥手要四次因全双工；主动方最后停 TIME_WAIT 等 2MSL；原因：① 旧报文消亡 ② 保最后 ACK 到达；2MSL=ACK存活1+重发FIN飘回1，是数学上界不是经验值。

### ⚠️ 错因记录
2MSL 初答错选"经验调参值"——混淆了"MSL 数值是工程经验"和"取 2 倍是数学推导"。**对策：2 倍 = 最坏情况 ACK 丢 + FIN 重发各 1 MSL。**
