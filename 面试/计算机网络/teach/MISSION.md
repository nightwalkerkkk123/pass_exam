# Mission: 计算机网络面试高频考点

## Why
技术面试中网络是必考板块（HTTP/HTTPS/TCP 三件套）。用户需要能在面试现场用自己的话讲清楚每个协议的核心设计动机，而不是背诵八股。能否拿到 offer、能否在系统设计题里讲清传输层权衡，都依赖这块的扎实程度。

## Success looks like
- 能按时间顺序讲清 HTTP/1.1 → 2 → 3 每一代解决的队头阻塞变种，并点出因果链（"HTTP/2 把流塞进一条 TCP，所以才有 TCP 层 HOL"）。
- 能画出 HTTPS 完整握手时序，讲清混合加密的分工；能解释 TLS 1.3 相比 1.2 砍了什么、为什么能砍。
- 能解释 TCP 四次挥手每一步的状态变化，并从最坏情况推导出 2MSL 的由来。
- 能做对"首次访问网站要几个 RTT"这类综合计数题。

## Constraints
- 面试导向：重"为什么"与"能讲出来"，轻 408/内核实现细节。
- 节奏：连环追问 + 选择题验证，遇到盲点当场展开。
- 中文表达，术语第一次出现要解释。

## Out of scope
- TCP 拥塞控制（慢启动、拥塞避免、BBR）——另立主题。
- IP 路由、NAT、DNS 详细机制。
- Socket 编程 API。
- HTTP 状态码、RESTful 设计（应用层语义，非传输）。
