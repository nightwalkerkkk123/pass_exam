# 计算机网络 Glossary

本术语表覆盖面试复习中**已确认用户掌握**的核心术语。只在用户能正确使用后才收录。

## HTTP 演进

**队头阻塞（Head-of-Line Blocking, HOL）**:
前一个请求/报文没处理完，后面所有请求都被堵住不能推进。HTTP 演进的主线矛盾，分应用层 HOL（HTTP/1.1）与 TCP 层 HOL（HTTP/2）两种。
_Avoid_: 堵塞、排队等待

**多路复用（Multiplexing）**:
一条 TCP 连接上同时承载多个流（stream），流被切成帧交错传输，互不堵塞。HTTP/2 的核心机制。
_Avoid_: 连接池、并发连接

**HPACK**:
HTTP/2 的头部压缩算法，用静态表 + 动态表 + 哈夫曼编码消除重复头部。

**QUIC**:
基于 UDP 的传输协议，在 UDP 之上自行实现可靠传输与加密；流独立可靠、连接可迁移。HTTP/3 的传输层。
_Avoid_: "UDP 不可靠"（QUIC 自己实现了可靠）

## 加密与 TLS

**混合加密**:
先用非对称加密协商出对称的会话密钥，之后通信用对称加密。非对称解决密钥传递，对称解决传输性能。

**数字证书**:
由 CA 签名的服务器公钥 + 身份信息。用来验证"这个公钥确实属于这家服务器"，防冒充。**不是用来加密数据的**。
_Avoid_: 证书加密（错）

**前向安全性（Forward Secrecy）**:
即使服务器长期私钥泄露，历史录制的流量也无法被解密。(EC)DHE 每次握手生成临时密钥对实现之；RSA 密钥交换没有此性质。

**0-RTT**:
TLS 1.3 会话恢复模式，客户端第一个包即可携带加密的应用数据。有重放攻击风险，只能用于幂等请求（GET）。

## TCP

**MSL（Maximum Segment Lifetime）**:
一个 TCP 报文段在网络中最长存活时间。Linux 默认 30 秒。
_Avoid_: TTL（IP 层跳数）、RTT（往返时延）

**TIME_WAIT**:
主动关闭方在四次挥手后进入的状态，等待 2MSL 才彻底关闭。两个目的：① 保最后 ACK 能到 ② 让旧报文消亡。

**2MSL**:
TIME_WAIT 的等待时长 = (ACK 最长存活 1 MSL) + (重发 FIN 最长传输 1 MSL)。**数学最坏上界，不是经验值**。
