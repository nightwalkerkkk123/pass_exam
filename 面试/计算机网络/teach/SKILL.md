# 计算机网络面试复习 — 教学入口

本课程覆盖技术面试高频的网络三件套：HTTP 演进、HTTPS/TLS 握手、TCP 连接管理。

## 教学状态文件
- `MISSION.md` — 为什么复习、成功标准、范围边界。
- `NOTES.md` — 用户偏好与教学法观察。
- `GLOSSARY.md` — 已掌握的术语（只在用户能正确使用后收录）。
- `lessons/` — HTML 微课（每节解决一个窄问题）。
- `learning-records/` — 学习记录（ADR 式的非显然洞察）。
- `reference/` — 速查资料（含 Obsidian 格式笔记）。

## 教学流程
1. 读 `MISSION.md` + `NOTES.md` + 最新 `learning-records/`。
2. 用连环追问 + 选择题验证（用户偏好）。
3. 类比先行，每个结论给"为什么"的推导。
4. 每节微课只解决一个窄问题，含直觉类比 + 关键定义 + 小表格 + ≥1 自测题。
5. 会话结束写 learning-record，记录纠正的误解与薄弱点。
