# 教学笔记 — 计算机网络

## 用户偏好（2026-08-05 首次会话观察）
- 节奏偏好：**连环追问**（模拟面试），不喜欢长篇铺垫；遇到不会的直接说"不会"，期待当场展开。
- 理解速度：选择题四连对（HTTP 演进、TLS 分工、TCP 根因），概念抓取快。
- 开口意愿：偏低，倾向"我懂了下一个"——综合验证环节需强制开口复述。

## 薄弱点（高价值信号）
1. **反向提问易踩坑**：在"下列哪项错误"题中误选了正确的描述。知识本身没问题，是审题问题。对策：先圈题干关键词再读选项。
2. **算 RTT 易漏段**：首次答"2 个 RTT"（正确 4 个），漏算 TCP 握手或 HTTP 往返。对策：算 RTT 题全程都要数，从第一个包到第一个有效字节。
3. **倾向选"经验值"类答案**：对"数学推导"类结论存疑（如 2MSL）。对策：每个数值结论都给最坏情况推导，不只给结论。

## 教学法
- 类比先行：收银台 → 传送带 → 独立快递通道（HTTP 三代）；明信片 → 加密信封（HTTPS）；挂电话（TCP 挥手）。
- 每个结论尽量给"为什么是这个值/这种设计"的推导。
- 选择题 + 反向题混合，训练审题。
